PaperPhone Plus

一款可自托管的全平台即时通讯应用。无状态 ECDH + XSalsa20-Poly1305 逐消息加密，覆盖私聊、群聊、朋友圈、公开时间线、视频语音通话与离线推送。

Secure by design

像日常聊天一样顺手，像私有基础设施一样可控。

最新版本围绕加密、跨端、推送、社交与内容治理继续扩展，既能作为个人私密通讯工具，也能作为团队自托管 IM 基础。

逐消息端到端加密

无状态 ECDH + XSalsa20-Poly1305，逐消息临时密钥，前向保密，支持 Signal 风格安全号码验证。私钥仅保存在设备本地。

零知识服务器

服务器只保存密文，私钥四层本地持久化：内存、localStorage、sessionStorage、IndexedDB。

加密群聊

群聊最高 2000 人，群主可切换加密模式；加密群使用 Sender Key 协议保护成员消息。

视频与语音通话

WebRTC P2P 与多人 Mesh，Cloudflare TURN 优先，Metered.ca 和公共 STUN 自动降级。

实时变声

语音消息、1v1 通话、群组通话支持 0.8x、1.0x、1.2x 三档变声，基于 Web Audio API。

离线消息可靠送达

Web Push、FCM、OneSignal、ntfy、APNS 五通道推送，覆盖浏览器、iOS PWA、原生 App 与无 Google 服务的安卓设备。

完整好友系统

好友审核、512 字验证消息、备注、12 色标签分组、黑名单与双向朋友圈隐私控制。

朋友圈与时间线

朋友圈支持图文视频、点赞评论和可见性；公开时间线采用小红书风格双列瀑布流。

扫码加好友/入群

二维码添加好友、加入群聊，群二维码可设置 1 周、1 月或 3 月有效期。

管理与审核

内嵌 Web 管理面板，支持举报审核、违规内容删除、用户封禁、路径自定义与密码保护。

Interface preview

从聊天到社交，都保持熟悉的移动端手感。

同步展示上游仓库最新截图预览，包含聊天、联系人、朋友圈、通话、设置、群聊、变声和更多页面状态。

Deploy & clients

云端一键启动，也可以完整自托管。

后端、数据库、缓存、对象存储和前端部署路径都已在上游文档中覆盖；官网保留最短入口，详细配置回到仓库查看。

推荐部署路径

Zeabur 可快速部署全套服务；Docker Compose 适合自有服务器；前端可独立部署到 Vercel，登录时填写后端地址即可连接。

阅读部署文档
1Zeabur 一键云部署，适合最快体验完整服务。
2Docker Compose 启动 client、server、MySQL、Redis。
3Vercel 托管前端，后端继续使用 Zeabur 或自有服务器。
